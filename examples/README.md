# Animal Island Cozy Markdown examples

Open either note in Obsidian with the Animal Island Cozy theme enabled. Use Reading view for fixed HTML divider/background swatches. Both files are independent, editable examples with matching sections in English and Traditional Chinese.

- [English](Animal%20Island%20Example%20-%20English.md)
- [繁體中文](Animal%20Island%20Example%20-%20中文.md)

Keep filenames and the relative `../docs/images/backgrounds.png` image path, or replace that image link with your own. For the calendar examples, set `island-date` and `island-empty-date` to Date and `island-time` to Date & time in the Properties type menu. These vault-level types are not stored in a Markdown file. Enable the optional Animal Island Calendar companion to use its picker.

Design based on [Animal Island UI by guokaigdg](https://guokaigdg.github.io/animal-island-ui/); adapted for Obsidian by Tiffany Iong. See the repository licenses and third-party notices.
