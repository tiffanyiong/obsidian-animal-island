# All callouts / 完整提示框圖鑑

13 built-in types / 13 種內建類型。Note 海鹽藍、Info 海灣藍、Tip／Hint／Important 海島藍綠。背景透明度與外框沿用 Style Settings。

Reading View 或 Live Preview 中點到區塊外即可查看樣式。

## Note / 筆記

> [!note] Note / 筆記
> Normal body text · 正文保持原樣。

## Question / 問題

`[!question]` · Native aliases / 原生別名：`help`, `faq`。本主題中 Question 為奶茶棕，Help／FAQ 為沙灘杏。

> Normal body text · 正文保持原樣。

> The answer appears here / 展開後顯示答案。

> [!question]+ Expanded question / 點我收合問題
> This answer starts visible / 此答案預設展開。
