# Animal Island Cozy — Complete Settings Reference

[README / installation and limitations](../README.md) · [Traditional Chinese usage guide](STYLE_GUIDE.zh-TW.md)



Independent language switching and translated option labels require the optional Animal Island Calendar companion. It works with unmodified Style Settings 1.0.9 and does not patch third-party files.
